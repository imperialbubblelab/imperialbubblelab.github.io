    How costs are counted here
    
          
      
            
    • n is the number of items in the data, and m the number of questions, or queries, asked of it.
      • 
            
    • Big-O keeps the part of a cost that grows fastest and drops constant factors: 3n² + 100n steps is O(n²).
      • 
            
    • When you choose a rate of growth, choose the tightest of the six: the slowest-growing one that always holds.
      • 
            
    • Costs are for the worst case unless a question says otherwise. Looking a value up in a set or dictionary counts as O(1) on average.
      • 
            
    • Logarithms are to base 2: log₂ 16 = 4, because 16 = 2⁴. Halving n again and again reaches 1 after about log₂ n steps.
      • 
            
    • To estimate a new running time, scale by the rate: tripling n multiplies an O(n²) time by 9, while doubling n multiplies an O(n log n) time by a little over 2.
      •

      Sorting
      

      # a new sorted list; values is unchanged
ordered = sorted(values)
# sorts values itself, and returns None
values.sort()
# largest first
sorted(values, reverse=True)

def mass(part):
    return part[1]

# sorted by what mass returns
sorted(parts, key=mass)
# the heaviest, in one pass
max(parts, key=mass)
