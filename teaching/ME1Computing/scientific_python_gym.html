    Reading a contract
    
          
      
            
    • Signature: a parameter with no default is required; one with a default is optional, and the default is used without comment.
      • 
            
    • For each argument, ask for its container, element type, shape and meaning, including units.
      • 
            
    • Returns: one object, a tuple to unpack, positions rather than values, a dictionary, or a result object with attributes.
      • 
            
    • Read warnings, and status flags such as success, before you use the answer.
      • 
            
    • Validate: a case with a known answer, a plausibility check, one choice varied, an independent method.
